# 📤 File Uploader Web App

A simple and stylish file uploader built with Node.js (serverless) and deployed on [Vercel](https://vercel.com). Users can upload files and view the uploaded list instantly.

![Screenshot](https://via.placeholder.com/800x400?text=File+Uploader+Preview)

---

## ✨ Features

- ✅ Upload files with nice UI
- 🧠 Auto-renames with timestamp
- 📁 File listing (auto-refresh)
- ☁️ Serverless-ready for Vercel
